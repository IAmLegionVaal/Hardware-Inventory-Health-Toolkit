# Hardware Inventory Health Toolkit

A read-only PowerShell toolkit for Windows hardware inventory and health context.

## Features

- Computer model and BIOS details
- CPU and memory summary
- Disk inventory and health context
- Battery status where available
- Network adapter inventory
- CSV, JSON, and HTML reports

## How to run

```powershell
powershell.exe -ExecutionPolicy Bypass -File .\Hardware_Inventory_Health_Toolkit.ps1
```

## Safety

Diagnostic-only. It reports hardware information for support review.
